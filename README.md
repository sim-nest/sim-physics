# sim-physics

`sim-physics` owns cross-domain contracts for lumped dynamic systems: explicit boundaries, stores, conjugate ports, spans, ordered events, event-split signed-work audits, proof policy, study influence, and findings. Validation happens before any solve. Continuous work remains a signed per-port record; instantaneous impulses remain explicit event transfers.

It owns no number domain, generic method, field or wave solver, scheduler, store implementation, codec framework, host effect, or kernel type. It composes quantities, Shapes, content ids, Claims, read-construct, cookbook, and Index tooling from their established owners. Closure is explicit and every crossing names a declared port.
