# sim-lib-physics-influence

This crate enforces the scientific policy that energy-derived information must
not select, rank, size, or control a conforming study. It adapts declared study
graphs to `sim-incremental-core`, admits a fail-closed influence lattice, and
turns a clean completion proof into an unforgeable `SelectionInput`.

Opaque/native transformations are unknown unless accompanied by a checked
transfer declaration. There is deliberately no capability or override path.
